📷 Live Camera

LIVE · auto

Each logged-in user's browser sends a fresh frame on the interval you set in Quiz Config → Step 2 (default 30s), from login until they log out. Nothing is stored in Google Drive — one overwriting row per user keeps the sheet tiny. Click a card to load that user's current frame. The quiz page must be opened over https for the browser to allow a camera; users who deny it are logged as Camera Denied and can retry from the assessment screen.
